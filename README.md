# Online HelpDesk - Campus System

An enterprise-grade campus help desk system built with ASP.NET Core MVC. It gives students a simple way to report campus issues and request services, while administrators track, manage and resolve those requests from a central dashboard.

## Overview

Campus facilities and services often rely on scattered emails and phone calls. This system brings everything into one portal: students submit requests, admins assign and monitor them, and service reports show how issues are being handled.

## Key Features

- Secure login and registration for students and admins
- Students can submit service requests and track their status
- Admin dashboard with an overview of requests and activity
- Facility management (add, update and oversee campus facilities)
- Facility oversight to monitor the condition and usage of facilities
- Service reports for tracking resolved and pending requests

## User Roles

**Admin**
- Manages facilities and requests
- Monitors activity from the dashboard
- Views service reports

**Student**
- Registers and logs in
- Submits service requests
- Tracks request status

## Tech Stack

- ASP.NET Core MVC
- C#
- SQL Server
- HTML, CSS, JavaScript
